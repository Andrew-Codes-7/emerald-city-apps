# Emerald City Apps

Homepage for [emeraldcityapps.com](https://emeraldcityapps.com): little apps for everyday life.

## What's here

- `index.html`: the homepage, with a "Notify me" launch-list signup (Netlify Forms)
- `privacy.html`: privacy policy, served at `/privacy`
- `og-image.png`: the image shown when the link is shared in texts and social posts
- Logo, header mark, favicon, and home-screen icon

## Deploying

Static site, no build step. Netlify deploys automatically on every push to `main`.
